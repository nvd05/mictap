# Что нового в mictap

## 0.13.0 — 2026-10-28
### Изменено
- **Время у фразы — по часам.** «21:39» вместо минуты сессии; под ним серым — минута сессии, для справки.
- **Дни — разделителями, как в мессенджере.** «Сегодня», «Вчера», «27 октября» над первой фразой дня; при прокрутке день держится сверху.
- **Таймер записи — с нуля.** Каждая запись считается от 00:00:00, даже если сессия уже длинная.
- **`mictap wait` и `mictap tail` — с временем по часам.** У ответа `session_started`, у каждой фразы `start_at` и `end_at` в ISO 8601 с часовым поясом: агент видит день и час, а не только «25-ю минуту». `tail` теперь отдаёт объект `{project, session, session_started, segments}` вместо голого списка.

## 0.12.1 — 2026-10-28
### Изменено
- **Понравившиеся модели — общие для всех проектов.** Сердечко в любом списке отмечает модель везде; прежние отметки проектов перенесены в общий список сами.
- **Окно проекта: модель — из списка, с поиском.** Тот же список, что и «Распознавание» над текстом: видеокарта или модель Router AI с ценой, понравившиеся сверху, набранный текст ищет по имени. Писать имя модели руками больше не нужно.
### Исправлено
- **Команда mictap в терминалах.** Установка из терминала Claude Desktop клала её в личную папку Claude, и обычные терминалы её не находили. Теперь установщики это проверяют до записи; `tools\run-outside.ps1` ставит, как из своего терминала.
### Добавлено
- **`tools/listen.sh` для агентов.** Ждёт, пока вы нажмёте «Отправить агенту» или остановите запись, и отдаёт сказанное одной строкой JSON.

## 0.12.0 — 2026-10-28
### Добавлено
- **Скрытые проекты.** «Скрыть проект» в его меню: проект пропадает из списка и из «Агентов», чтобы его не увидели через плечо. Кнопка с глазом над проектами показывает скрытые, после перезапуска они снова спрятаны. Агентам скрытые проекты доступны.
- **Закреплённые проекты.** «Закрепить наверху» в меню проекта: такие проекты стоят первыми, с булавкой.
### Изменено
- **«Что нового» — в виде «Записей».** Версии — как дерево проектов, изменения — обычным текстом, без цветных значков.
- **Репозиторий:** README со снимками окна и этот список изменений — в папке docs.

## 0.11.0 — 2026-10-28
### Добавлено
- **Боковое меню.** «Записи», «Агенты», «Настройки», «Что нового» — на 9 часов.
- **Раздел «Агенты».** Все агенты всех сессий: кто ждёт, кто думает, кто ушёл, в каком проекте и сессии, когда был. На значке — сколько ждут.
- **Раздел «Что нового».** Этот список изменений по версиям.
- **Тестовый профиль.** `MicTap.App.exe --profile <папка>` — копия mictap со своими настройками и логами рядом с основной, без хоткеев. Проверки не трогают ваши настройки.
### Изменено

- **Контекстные меню — скруглённые**, с отступами, тонкой обводкой и тенью; пункты подсвечиваются скруглённо.
### Исправлено
- **Пустой значок на панели задач.** Ярлык mictap ведёт туда, где приложение лежит на самом деле.
